# LeetCode-Solutions

My daily DSA practice in Java — written for clarity, solved by hand, and synced with LeetHub.

Score one for every solved problem; a clean read is worth more than cleverness.

## Language

- Java (JDK 17+ compatible)

Open any problem folder, read the `Solution.java`, and run it with a local JDK. Each solution includes the problem statement for pace of review.
